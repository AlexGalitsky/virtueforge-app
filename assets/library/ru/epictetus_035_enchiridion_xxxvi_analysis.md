### Философский контекст
В этом тексте Сенека подчеркивает важность различия между едой как для тела и едой как для общества. Он подчеркивает, что хотя еда имеет значение для тела, она не имеет значения для сохранения стыдливого поведения и общности на пиру.

### Суть
* Важно различать еду как для тела и еду как для общества.
* Еда для тела является физической потребностью, а еда для общества — социальным аспектом.
* Стыд и общность на пиру имеют важное значение для сохранения социальных норм и поведения.

### Форма этой версии
Проза.

### Связь с добродетелью
Стид является ключевым аспектом добродетели, поскольку он помогает нам mantener социальные нормы и behave в соответствии с ожиданиями общества. Следовательно, сохранение стыда перед лицом устроителя пира имеет важное значение для поддержания добродетели.
