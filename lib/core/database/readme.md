🔍 Ключевые архитектурные решения в этом коде:

1. **Реляционная связь (`references`)**: Поле `stoicCategoryId` связывает
   добродетели Франклина со стоическими категориями. Это позволит вам одним
   SQL-запросом посчитать, например, сколько суммарно «страйков» (ошибок)
   совершил пользователь в категории _«Умеренность»_ за месяц.
2. **Уникальный ключ (`uniqueKeys`)**: Связка `date` + `virtueId` гарантирует,
   что база данных не продублирует записи за один и тот же день. При сохранении
   вечернего лога вы будете использовать операцию `InsertMode.insertOrReplace`.
3. **Разделение рефлексии (`noteControlled` / `noteUncontrolled`)**: Поля
   дневника разделены на основе стоической _дихотомии контроля_, заставляя
   пользователя ментально разделять события дня.

⚡ Пример реактивного SQL-запроса (BAsic DAO / Repository)

Чтобы Flutter-интерфейс (через Bloc/Riverpod) автоматически перерисовывался при
добавлении «черной точки», Drift предоставляет `watch` -запросы. Вот как будет
выглядеть запрос для получения статистики по стоическим категориям:

```
// Внутри класса AppDatabase или отдельного DAO:

/// Стрим, который отдает топ категорий по количеству ошибок (срыв добродетелей)
Stream<List<TypedResult>> watchStoicProgress() {
  final countStrikes = dailyLogs.strikesCount.sum();

  return (select(stoicCategories)
      .join([
        innerJoin(franklinVirtues, franklinVirtues.stoicCategoryId.equalsExp(stoicCategories.id)),
        innerJoin(dailyLogs, dailyLogs.virtueId.equalsExp(franklinVirtues.id)),
      ])
      ..addColumns([countStrikes])
      ..groupBy([stoicCategories.id]))
      .watch();
}
```

🧱 Что это дает вашему приложению?

1. **Мгновенный холодный старт**: Пользователю не нужно вручную вбивать 13
   качеств или категории при первом запуске приложения. На первом же экране он
   увидит готовую структуру.
2. **Индексация недель (`defaultWeekNumber`)**: Каждому качеству присвоен
   оригинальный номер Франклина. Ваша бизнес-логика (в Bloc/Riverpod) сможет
   легко вычислять текущую неделю цикла, просто используя оператор деления по
   модулю: `currentWeekOfYear % 13`.
3. **Безопасность транзакций**: Благодаря использованию метода `transaction()`,
   если во время записи 5-й добродетели произойдет сбой (например, выключится
   телефон), база данных откатится к чистому состоянию. Ошибок «битых» или
   наполовину заполненных данных не возникнет.
